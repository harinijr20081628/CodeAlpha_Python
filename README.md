CodeAlpha Python Programming Internship

This repository contains the tasks completed as part of the CodeAlpha Python Programming Internship.

Tasks Completed

1. Hangman Game (Hangman_Game.py)

A classic word-guessing game built in Python.

- Random word selection
- Limited number of wrong guesses allowed
- Displays word progress and remaining attempts
- Win/lose messages at the end

How to run:

python Hangman_Game.py

2. Chatbot (Chatbot.py)

A simple rule-based chatbot that responds to predefined questions and greetings.

- Responds to greetings, small talk, and basic questions
- Provides responses related to AI, Python, Machine Learning, Data Science, etc.
- Type "bye" or "exit" to end the conversation

How to run:

python Chatbot.py

3. Stock Portfolio Tracker (stock_portfolio_tracker.py)

A simple Python-based stock portfolio tracker that allows users to manage their stock investments.

- Add stocks to the portfolio
- Enter stock name, quantity, and buy price
- View portfolio details
- Calculate individual investment value
- Calculate total investment

How to run:

python stock_portfolio_tracker.py
